# P16:Goal 模式(自治多轮)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 手机下发目标 → daemon 上自治多轮续跑 → blocked/complete 通知。goal 是 runtime 持有的结构化状态机(active/paused/blocked,complete 瞬时清除,无 cancelled);模型**只能**经注入的 `updateGoalStatus` 工具收束,自然语言无效;driver 每次跑一个普通 turn,读 P12 stopReason 与 goal 状态决定续跑/停车;注入只在 turn 边界;重启恢复 active→paused;maxTurns 默认 20 硬顶。组合前四项:P13 自愈瞬时错误、P14 锁屏断线补发与 session 级 abort、P15 长跑压缩。Spec:`docs/superpowers/specs/2026-07-21-kimi-code借鉴五项改进-design.md` §7(契约 C16-1~C16-8)+ kimi GOAL.md 核心工作流。

**Architecture:** wire(goal-create/goal-control 入站 + goal-updated 事件)→ agent-core(`extraTools` 注入点 + goal prompt 模板,通用能力)→ server(`goal/` 模块:状态机纯函数 + driver;agent.ts 挂注入与工具、返回 turn 结果;messageHandler 分发;db 加列)→ app(`/goal ` 前缀入口 + goal 卡片 + 通知)。geek 模式不支持 goal(driver 生在 daemon,锁屏自治正是价值点)。

**Tech Stack:** TypeScript(ESM,`.js` 后缀)、zod v3、vitest(**不是 jest**)、pnpm workspace、sql.js(db 迁移)。

### Task 3: server — goal 状态机与 driver(TDD)

**Interfaces(Produces):**

```ts
// goal/types.ts
export interface GoalState {
  goal: string;
  acceptance?: string;
  status: "active" | "paused" | "blocked" | "complete";  // complete 瞬时(D-P16-2)
  stopReason?: string;
  stats: { turns: number; inputTokens: number; outputTokens: number; startedAt: number };
  budgets: { maxTurns: number };
  createdAt: number;
  updatedAt: number;
}
export function createGoal(content: string, acceptance?: string, maxTurns?: number): GoalState; // 默认 20
export function goalUpdatedEvent(g: GoalState, change: "lifecycle" | "completion"): AgentEventType;
export function clearedEvent(stats: GoalState["stats"]): AgentEventType;

// goal/driver.ts
export interface GoalDriverDeps {
  runAgent: typeof runAgent;                      // 可注入(测试 mock)
  persistGoal: (sessionId: string, goal: GoalState | null) => void;
  publish: (ev: AgentEventType) => void;
}
/** 前置:session.goal 存在且 active。返回时 goal 已停在终态或被清除,事件已发、已持久化。 */
export async function runGoalDriver(session: AgentSession, deps: GoalDriverDeps): Promise<void>;
```

**driver 循环(spec §7.1 + D-P16-4,伪码即实现结构):**

```
idleTurns = 0
while (session.goal?.status === "active"):
  g = session.goal
  if g.stats.turns >= g.budgets.maxTurns: 停车(blocked, "已达轮数预算"); break
  g.stats.turns++
  content = g.stats.turns === 1 ? goalKickoffPrompt(g) : GOAL_CONTINUATION_PROMPT
  before = g.updatedAt
  abort = new AbortController(); session.currentAbort = abort
  outcome = await deps.runAgent(session, content, deps.publish, abort.signal)
  session.currentAbort = undefined
  if outcome: g.stats.inputTokens/outputTokens += outcome.usage.*
  if !session.goal: break                                   // turn 中被 cancel
  if g.status === "complete":
      deps.publish(goalUpdatedEvent(g, "completion")); session.goal = undefined
      deps.persistGoal(sessionId, null); break
  if g.status === "paused" || g.status === "blocked": 停车通告; break   // 工具/control 已置态
  if !outcome || outcome.stopReason === "error":  停车(paused, "技术错误,已暂停"); break
  if outcome.stopReason === "aborted":            停车(paused, "用户中断"); break
  if outcome.stopReason === "end_turn" && g.updatedAt === before:
      if ++idleTurns >= 3: 停车(blocked, "连续多轮无进展"); break        // D-P16-4
  else: idleTurns = 0
  // max_steps → 直接续跑(自动"继续",C16 与 P12 的组合点)
  deps.persistGoal(sessionId, g)
// 停车(status, reason) = 置态+updatedAt → persistGoal → publish(goalUpdatedEvent(g,"lifecycle"))
```
